# 路线图 / Roadmap

拾贴优先把文本历史、搜索、编辑和数据保存做好。下面是候选方向，用于讨论，不代表已经实现或承诺交付日期。

ShiTie focuses on dependable text history, search, editing, and local storage. These are discussion candidates, not shipped features or dated commitments.

| 候选方向 / Candidate | 目标 / Goal |
| --- | --- |
| 英文界面 / English localization | 让非中文用户也能直接使用 / Make the app accessible to English-speaking users |
| 分发体验 / Distribution | 探索 Developer ID 签名、公证和 Intel 下载包 / Explore notarization and an Intel binary |
| 快捷访问 / Quick access | 讨论全局呼出与开机启动的原生实现 / Discuss native global activation and launch at login |
| 数据迁移 / Data portability | 设计显式导入导出，明确敏感数据边界 / Design explicit import/export with clear data controls |

欢迎到 [Issues](https://github.com/wangleijie5859/ShiTie/issues) 说明使用场景、遇到的障碍和期望的行为。
